Import staff from a spreadsheet

Choose an Excel or CSV file, or copy the columns from Excel and paste them below. You need three columns: name, Workday ID (full ID or last 4), and department. Staff already on the roster with the same name and last 4 are updated, not duplicated.

Import topics from a spreadsheet

Choose an Excel (.xlsx) or CSV file with one row per question and these column headings: Topic title, Question, Correct answer, Wrong answers. Optional: Lesson text, Department, Hint, Explanation, Category, Last-used date. Separate several answers in one cell with |. Rows with the same topic title become one topic with several questions. A question containing "select all" becomes select-all-that-apply. Topics already in your library with the same title are updated.
